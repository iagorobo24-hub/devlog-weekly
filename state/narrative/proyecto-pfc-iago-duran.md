Semana 1: Inicio del proyecto con enfoque en migraciones a TypeScript, implementación de modo local/cloud con Supabase, optimizaciones de rendimiento y actualizaciones de dependencias. Se migró sonexCatalogContext a TypeScript, configuró Supabase para modos local y cloud, y se mejoró la infraestructura. Dependencias clave actualizadas, PRs cerrados para estabilizar runtime, mejorar seguridad y calidad, y se introdujeron tags v3.0.0 y v2.0.0.

Semana 2: Se añadió el routing inicial para la sección PSM, aunque la arquitectura aún no está certificada. Se creó un manifiesto de discovery remoto en estado draft, definiendo la estructura de los servicios que serán descubiertos. Se corrigió el esquema de fecha en el manifiesto draft para cumplir con los requisitos de validación. El proyecto sigue consolidando la base de rutas y manifiestos, manteniendo la migración a TypeScript y la configuración de Supabase, y afinando la capa de datos y la interfaz de usuario.
