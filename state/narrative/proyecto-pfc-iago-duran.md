Semana 1: Inicio del proyecto con un enfoque en migraciones a TypeScript, implementación de modo local/cloud con Supabase, optimizaciones de rendimiento y actualizaciones de dependencias para asegurar una base sólida y escalable. Se resaltan la migración de `sonexCatalogContext` a TypeScript, la configuración de Supabase para modos local y cloud, y mejoras en infraestructura. Dependencias clave fueron actualizadas. Se cerraron PRs para estabilizar la runtime, mejorar seguridad y calidad, y se introdujeron tags `v3.0.0` y `v2.0.0`.
